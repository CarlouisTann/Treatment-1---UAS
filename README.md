# Project Web Sederhana

Project ini dibuat menggunakan HTML, CSS, dan JavaScript.

## Fitur
- Form input data
- Tabel data
- Simpan data menggunakan localStorage
- Layout responsif

## Cara Menjalankan
1. Download atau clone repository
2. Buka file `index.html` di browser
3. Input data lalu lihat hasilnya di `tabel.html`

## Struktur Folder
- index.html
- tabel.html
- style.css
- script.js
